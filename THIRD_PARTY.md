# Third-party components

Xuan's own source code is MIT licensed. Dependency licenses remain applicable to their respective code.

- **Rawler 0.8.0** provides Nikon and Canon RAW decoding, camera calibration data, and PPG demosaicing. Copyright Daniel Vogelbacher, Pedro Côrte-Real, and the Rawler contributors. Licensed under the GNU LGPL 2.1; see [the license](licenses/rawler-LGPL-2.1.txt) and [upstream source](https://crates.io/crates/rawler/0.8.0).
- **RAW test fixtures**: seven camera files from [raw.pixls.us](https://raw.pixls.us/), each released by its contributor under [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/). They are downloaded by `scripts/fetch-raw-fixtures.sh` for tests only, are not committed or shipped, and are listed with their sources in [testdata/raw/README.md](testdata/raw/README.md).
- **heic-rs 0.1.1** provides HEIC/HEIF decoding in Rust. The decoder and synthetic regression fixtures are used under the [MIT license](licenses/heic-rs-MIT.txt); see [upstream source](https://crates.io/crates/heic-rs/0.1.1) and [fixture provenance](src/io/fixtures/README.md).
- **seccompiler 0.5.0** (Linux builds only) compiles the seccomp filter that blocks the network of plugins that declare none. Copyright 2021 Amazon.com, Inc. or its affiliates. Dual-licensed under Apache-2.0 or BSD-3-Clause; Xuan uses it under the [BSD 3-Clause license](licenses/seccompiler-BSD-3-Clause.txt); see [upstream source](https://crates.io/crates/seccompiler/0.5.0).
- **ureq 3, rustls 0.23, rustls-platform-verifier and ring 0.17** download the model files plugins declare, over https. ureq and rustls-platform-verifier are MIT or Apache-2.0, rustls is Apache-2.0, ISC or MIT, rustls-webpki is ISC, and ring is Apache-2.0 and ISC; see their upstream sources on crates.io. They are compiled into the executable: no OpenSSL or other TLS library is linked, and certificates are checked against the operating system's trust store (on Linux, the CA bundle of the `ca-certificates` package), so no root certificates are bundled.
- **MCP server plugin** (`lib/xuan/plugins/mcp-server` on Linux, `plugins\mcp-server` on Windows): a separate program, MIT like Xuan, built with the official Rust MCP SDK [rmcp](https://crates.io/crates/rmcp) (Apache-2.0), [axum](https://crates.io/crates/axum), [hyper](https://crates.io/crates/hyper) and [tokio](https://crates.io/crates/tokio) (MIT), and [base64](https://crates.io/crates/base64), [getrandom](https://crates.io/crates/getrandom) and [serde_json](https://crates.io/crates/serde_json) (MIT or Apache-2.0); the full list is in `plugins/mcp-server/Cargo.lock` in the source archive. The Linux build is statically linked with the [musl C library](https://musl.libc.org/) (MIT).
- **Droid Sans Fallback Full**: Chinese UI and filename glyphs, Copyright 2005–2008 The Android Open Source Project, [Apache License 2.0](assets/fonts/DroidSansFallback-LICENSE.txt). Bundled unmodified from the Android Droid font family.
- **Inter Variable**: [SIL Open Font License](assets/fonts/Inter-LICENSE.txt).
- **Tabler Icons**: toolbar and layer-control SVGs use [Tabler Icons](https://tabler.io/icons), licensed under the [MIT license](licenses/tabler-icons-MIT.txt).
- **egui-winit**: [MIT](vendor/egui-winit/LICENSE-MIT) / [Apache 2.0](vendor/egui-winit/LICENSE-APACHE), with local patches retained in the accompanying source archive.
- **AppImage runtime libraries**: Linux AppImages also bundle X11/Wayland client libraries, libgcc, glibc, and its matching dynamic loader. Their copyright and license notices are included under `usr/share/doc/` and `usr/share/licenses/` inside the image, with glibc notices under `usr/share/licenses/glibc/`; extract it with `--appimage-extract` to inspect them.
- **sRGB ICC profile**: generated with Little CMS through Pillow's `ImageCms.createProfile("sRGB")`. The profile is embedded in Develop's 16-bit TIFF exports; generating it is not a build or runtime requirement.

Every release provides a matching `xuan-<version>-source.tar.gz` alongside the binary packages on [GitHub Releases](https://github.com/silverling/xuan/releases). It contains Xuan's build sources, the patched egui-winit sources, and the exact Rawler sources used in the executable. Binary packages include a `SOURCES.md` notice with the exact archive name and download link. Distribute this source archive alongside the binaries and retain equivalent access to it when redistributing them.

To rebuild or relink with a modified Rawler, extract the source archive into a writable directory, enter `xuan-<version>-source`, edit `vendor/rawler` if desired, then run `cargo build --release --locked`. A Rust toolchain, a C toolchain, the platform prerequisites listed in the [development guide](docs/DEVELOPMENT.md#prerequisites), and access to the Cargo registry for other dependencies are required. The source manifest patches Rawler to the included directory, and its lockfile is resolved for that path dependency. GitHub's automatically generated source archives do not include these vendored Rawler sources.
